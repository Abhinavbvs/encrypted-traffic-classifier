01 · Capability

PCAP ingestion

Raw .pcap and .pcapng in, bidirectional flows out.

In short

Native Scapy parser builds 5-tuple flows and throws payload bytes away on arrival.

Run it →

From capture file to flows

src/pcap_extractor.py reads standard .pcap and .pcapng files with Scapy. It needs no proprietary tools and no decryption keys.

  • Extracts IPv4 and IPv6 network headers and TCP and UDP transport ports.
  • Discards payload bytes as packets are read, so they never reach memory beyond the parser.
  • Builds bidirectional flows on a canonical key: (IP_min, IP_max, Port_min, Port_max, Protocol).
  • Tracks the initiator so every packet is labelled forward (client to server) or backward (server to client).

Built to survive bad input

The test suite covers empty and corrupt captures, so a truncated file returns a clean error instead of a crash.

# classify a raw capture directly
python src/predict.py --pcap data/sample_pcaps/voip_call.pcap --threshold 0.5

Four captures included

data/sample_pcaps/ ships ground-truth captures for browsing, VoIP, streaming and file transfer, generated by src/generate_sample_pcaps.py, so you can test without capturing anything yourself.
