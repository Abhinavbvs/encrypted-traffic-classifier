02 · Capability

Timing features

23 statistics about when packets move, nothing about what they carry.

In short

Inter-arrival times, throughput, active bursts and idle gaps, computed per flow.

Run it →

Why timing works

Encryption changes the bytes but not the cadence. A voice codec has to send a frame every 20 ms. A bulk upload has to saturate the link. A person reading a page leaves an idle gap. These rhythms survive TLS 1.3 and QUIC, and they are hard to fake without breaking the application.

The 23 features

Computed per flow over a 15 second window, with a 5.0 s threshold separating active bursts from idle periods.

flowdurationTotal flow duration (µs)
fwdtotal_fiatTotal forward inter-arrival time
bwdtotal_biatTotal backward inter-arrival time
fwdmin_fiatShortest forward gap
fwdmax_fiatLongest forward gap
fwdmean_fiatMean forward gap
bwdmin_biatShortest backward gap
bwdmax_biatLongest backward gap
bwdmean_biatMean backward gap
rateflowPktsPerSecondPacket rate
rateflowBytesPerSecondByte rate
flowmin_flowiatShortest gap, either direction
flowmax_flowiatLongest gap, either direction
flowmean_flowiatMean gap, either direction
flowstd_flowiatGap variability
burstmin_activeShortest active burst
burstmean_activeMean active burst
burstmax_activeLongest active burst
burststd_activeBurst variability
idlemin_idleShortest idle period
idlemean_idleMean idle period
idlemax_idleLongest idle period
idlestd_idleIdle variability

No leakage

The StandardScaler was fitted on the training split only and saved as models/scaler.pkl. Validation, test and live flows are transformed with it but never fitted.
