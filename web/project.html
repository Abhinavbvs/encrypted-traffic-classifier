MetaFlow/Project
05 · Project

Privacy is the architecture.

MetaFlow is the landing name for encrypted-traffic-classifier, an open-source framework that classifies encrypted network flows from timing statistics alone, and explains why.

The problem

Encryption won. Visibility didn't have to lose.

Most traffic now travels over TLS 1.3 or QUIC. Deep packet inspection needs decryption keys, breaks privacy law and costs heavy hardware. Port-based rules fail because nearly everything shares port 443. Deep learning works but needs GPUs and explains nothing.

MetaFlow takes a different route. It treats each flow as a rhythm of packets moving in two directions and learns which rhythm belongs to which application, using 23 timing features, a LightGBM model and an explanation layer that speaks networking.

Principles

What we would not compromise.

i

No payload

If a feature needs payload, it does not ship.

ii

No leakage

Scaler fitted on train only. Test set held out from the start.

iii

No black box

Every verdict carries a reason a network engineer can check.

iv

No forced guesses

Low confidence becomes "unknown", not a wrong label.
