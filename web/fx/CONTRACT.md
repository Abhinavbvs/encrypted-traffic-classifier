## 3D shapes (owned by the shapes agent, used by everyone)
Place `<canvas class="mf-shape" data-shape="cube|dish|cone|torus|capsule|sphere|arch|pyramid" data-size="160"></canvas>`
anywhere (CSS sets its box). Optional: data-spin="0.4" (rad/s), data-drag (user can drag-rotate with inertia),
data-float (gentle bob), data-par="0.15" (scroll parallax factor), data-tint="mag|chrome|violet".
The engine (web/js/fx/05-shapes.js) renders glossy chrome + magenta shapes with WebGL and exposes MF.shapes.mount(canvas).
If WebGL is missing it draws a Canvas2D fallback. Do not build your own shape renderer — just place canvases.

## Facts you may use (nothing else — do not invent numbers or claims)
MetaFlow = landing name of encrypted-traffic-classifier. Classifies encrypted traffic (TLS 1.3/QUIC) into 7 classes —
VoIP, Browsing, Streaming, FileTransfer, P2P, Chat, Mail — using ONLY 23 timing features, zero payload inspection.
LightGBM model. 96.9% held-out test accuracy (0.9686), macro F1 0.950 (0.9497), 1,305 unseen test flows.
5-fold CV: LightGBM 95.61% ± 0.57%, XGBoost 95.18%, Random Forest 93.90%. ~2.3 ms per flow on CPU (2.312), >400 flows/s.
Dataset ISCX VPN-NonVPN 2016: 8,965 raw → 8,694 clean flows, 70/15/15 split (6,085 / 1,304 / 1,305). 32 tests passing.
Pipeline: PCAP/PCAPNG → Scapy header parsing (payload discarded) → bidirectional 5-tuple flows → 23 features (FIAT, BIAT,
flow IAT, rates, active/idle bursts, 5 s idle threshold) → StandardScaler (train-only) → LightGBM → top-3 + probabilities →
explanation (Tier 1 local Ollama, Tier 2 Groq/OpenAI, Tier 3 offline rule engine) → confidence threshold flags "Unknown".
Compared with DPI (needs keys, 100–500 ms, privacy issues), port rules (fail on 443), deep learning (GPU, 15–40 ms, black box).
Stack: Python 3.11, Scapy, LightGBM, scikit-learn, XGBoost, pandas, NumPy, Streamlit, Ollama, Docker, pytest, GitHub Actions.
MIT licence. Repo: https://github.com/Abhinavbvs/encrypted-traffic-classifier . Local server: python web/server.py → :8600.
Pages: index, benchmarks, capabilities (+5 capability-*.html: pcap-ingestion, timing-features, lightgbm, explainable-ai,
unknown-detection), analyze, project, demo, reports, get-started, system, license, privacy, security.
